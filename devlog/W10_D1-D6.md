## D1: Full Benchmark Matrix
- **Goal:** Execute a comprehensive benchmark across four distinct operational configurations with 3 repetitions (cold and warm passes), persisting all raw CSV logs and environment telemetry.
- **Implementation:** Created [`benchmarks/run_full_benchmark.py`](file:///D:/cc/prep/aegisflow/benchmarks/run_full_benchmark.py).
- **Configurations Evaluated:**
  1. `baseline`: Raw dense retrieval over corpus.
  2. `orchestrated`: Full 9-node LangGraph workflow (`Planner` → `Guard` → `Retrieve` → `Analyst` → `Verifier` → `Reporter`).
  3. `optimised`: Warm repeat queries utilizing E3 LRU + TTL caching.
  4. `optimised_load`: Multi-threaded concurrency ($c=4$) under warm caching.
- **Empirical Results (`benchmarks/results/`):**
  - `baseline`: p50 = 2,187.5 ms, p95 = 2,317.8 ms, Throughput = 0.45 req/s, Hit Rate = 0.0%
  - `orchestrated`: p50 = 92,193.1 ms, p95 = 92,193.1 ms, Throughput = 0.01 req/s, Hit Rate = 0.0%
  - `optimised`: p50 = 0.20 ms, p95 = 0.40 ms, Throughput = 222.22 req/s, Hit Rate = 100.0%
  - `optimised_load`: p50 = 0.20 ms, p95 = 0.40 ms, Throughput = 222.22 req/s, Hit Rate = 100.0%
- **Artifacts Generated:** 12 raw per-repetition CSVs and JSON summaries, `environment.json`, and `full_benchmark_summary.json`.
