# W3 D4-D6: Verifier, E1 review, and baseline-v2

Checked 2026-10-30.

## D4: Evidence sufficiency and abstention

`generation.py` now applies a cosine-distance/RRF score gate, then asks the
configured local judge whether the retrieved parent evidence can answer the
question. A negative verdict returns an abstained result with `missing` details
and no citations. The API exposes `abstained`, `missing`, and the separate
`verifier_sufficient` verdict. The API path defaults to verification; the eval
CLI has `--no-verifier` for matched comparisons.

The threshold start points are max RRF 0.015 and best cosine distance 0.82.
They are not calibrated thresholds. The full E1 run, which uses parent-child
retrieval but no verifier, achieved 80% prompt-only refusal on ten unanswerable
questions and 100% coverage on 31 answerable questions. The score-only sweep at
RRF >= 0.015 still accepted every unanswerable tuning question and 80% of the
held-out unanswerables. Thus the score gate alone is too weak; the judge must
contribute materially for this feature to work.

The tradeoff plot uses answerable retrieval evidence-hit rate as a proxy for
correctness. It is not a substitute for answer grading. See
`results/abstention_tradeoff.svg` and
`results/baseline_E1_answer_quality.json`.

## D5: E1 baseline and judge calibration status

The 41-question E1 parent-child answer run used k=3, Gemma 3 4B, and one run per
question. Thirty answers completed and eleven failed structured-answer
validation after the retry. Mean source Recall@3 was 0.500, median per-question
latency 19.482 seconds, and P95 46.261 seconds. Citation precision/recall were
0.200/0.111 using exact source-section matches.

E2 uses Qwen 3.5 4B for evidence sufficiency, separated from Gemma 3 4B answers.
A 41-question run and two 20-question stratified retries stalled without an
output CSV. The 20-question subset includes ten unanswerables and ten answerable
questions including conflicting-document cases. The verifier was then changed
to send matched child excerpts instead of full parent passages; the retry still
made no observable progress. A short structured judge request took about 90
seconds. See `docs/ADR-003-abstention-and-grader.md` for the status and
reproduction commands.

No E2 judge-agreement number is claimed. The 20-answer human review sheet can be
generated once E2 completes; then binary human labels and agreement should be
recorded in ADR-003.

Added eleven cases (six conflicting-document cases and five additional
