# W7 D1-D6: Observability, UI & CI Quality Gates (Milestone 2)

**Date:** 2026-11-10

## Built

- **D1 OpenTelemetry Tracing:**
  - Implemented OpenTelemetry tracing in `src/aegisflow/tracing.py` using in-memory collection and hierarchical span tree reconstruction (`build_trace_tree`).
  - Formatted spans following GenAI semantic conventions (`gen_ai.request.model`, `gen_ai.usage.prompt_tokens`, `gen_ai.usage.completion_tokens`, `gen_ai.usage.total_tokens`).
  - Context-propagated tracing across workflow run root (`trace_workflow_run`), individual nodes (`trace_node`), structured LLM calls (`trace_llm_call`), hybrid retrieval (`trace_retrieval`), and tool execution (`trace_tool_execution`).
  - Exposed `GET /v1/runs/{run_id}/trace` in `src/aegisflow/api.py` for client inspection.

- **D2 Prometheus Metrics & Grafana:**
  - Implemented Prometheus instrumentation in `src/aegisflow/metrics.py` with strictly low-cardinality label sets (preventing TSDB memory leaks; zero `run_id` or question text in labels).
  - Metrics exposed:
    - `aegisflow_node_duration_seconds` (histogram with buckets calibrated from W5–W6 latency data)
    - `aegisflow_active_runs` & `aegisflow_queue_depth` (gauges)
    - `aegisflow_tokens_total` (counter by model and token type)
    - `aegisflow_workflow_retries_total` (counter by node)
    - `aegisflow_errors_total` (counter by component and error type)
    - `aegisflow_cache_hits_total` (counter by cache component)
    - `aegisflow_tool_calls_total` (counter by tool, decision, and outcome)
    - `aegisflow_tool_duration_seconds` (histogram)
  - Exposed `/metrics` endpoint in `src/aegisflow/api.py` (exempt from API key auth).
  - Authored `docs/grafana_dashboard.json` with live panels for p50/p95 latency, queue depth, token rates, tool decisions, and error/retry rates.

- **D3 Streamlit UI: Live Execution:**
  - Implemented `ui/app.py` featuring a Run Console with preset and custom incident questions, top_k controls, live visual timeline of workflow execution, and cancel controls.
  - Persisted `run_id` in `st.session_state["run_id"]` across Streamlit reruns.
  - Implemented SSE streaming client with polling fallback for live status updates.

- **D4 UI: Evidence, Reports & Inspector:**
  - **Evidence Panel:** Interactive citation inspection where clicking any citation highlights its exact supporting passage in `<mark>` tags. Offsets are calculated relative to normalized passage text to eliminate highlight drift.
  - **Structured Report:** Displays diagnosis, confidence, unknowns/missing facts, and risk-labelled remediation steps (`[LOW]`, `[MEDIUM]`, `[HIGH]`).
  - **Run Inspector:** Visual hierarchical OpenTelemetry span tree showing execution duration, status, model name, and token counts, alongside raw trace JSON.
  - **Tool Sandbox:** Interactive testing harness for model tool proposals against the central execution boundary.

- **D5 CI & Evaluation Gates:**
  - Created deterministic retrieval fixture suite in `tests/fixtures/ci_eval_fixtures.json`.
  - Built `evals/ci_eval_gate.py` computing Recall@k and MRR with tolerance checking against baseline.
  - Added `--simulate-regression` flag to verify gate behavior on degraded performance.
  - Created GitHub Actions workflow `.github/workflows/ci.yml` running lint, format check, typecheck, unit tests, and CI evaluation gate on standard GPU-independent runners.
