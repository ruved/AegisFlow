# W4 D1-D6: Typed workflow and observability

**Date:** 2026-10-31

## Built

- Added a TypedDict `RunState`, Pydantic schemas for planner, analyst, reporter,
  verifier, rewrite, citations, and public reports.
- Added bounded LangGraph assembly behind `run_workflow()`. The single router checks
  step, token, retry, and deadline limits and routes to finish, one rewrite, or abstain.
- Added JSON per-node logs and returned telemetry with run ID, duration, token counts,
  estimated-count marker, cache status, and result status. Attempt telemetry uses a
  stable event key and the adapter deduplicates reducer-backed histories.
- Added fake-service graph coverage, valid-report coverage, schema validation,
  loop detection and budget-stop checks.
- Added `evals/run_e4.py` and `evals/evaluate_planner.py` for reproducible E4 and
  planner-validity measurements.

## Verified

- `uv run python -m pytest -q`: 112 passed.
- `uv run ruff check .`, `uv run ruff format --check .`, and `uv run mypy src`: passed.
- A live one-question graph run emitted JSON logs with run IDs and per-node timings.
- The six-case E4 pilot measured 100% planner schema validity, zero gold-source task
  completion on three answerable questions, correct abstention on two of three
  unanswerable questions, and 92.3 s median latency versus 28.1 s for matched E1.
  See [ADR-004](../docs/ADR-004-e4-workflow.md) and the two pilot result CSV/JSON pairs.
- The dedicated planner check returned valid, bounded outputs on 15/15 questions
  (10 single-hop, five multi-part) with Gemma 3 4B; mean call latency was 9.06 s.
  This is schema validity, not a human semantic-quality score.

## Review

The workflow does not beat the baseline on the pilot and is more than three times
slower. Keep it experimental; do not wire it into the default API. A full 41-question
run, end-to-end multi-part cases, held-out evaluation, and human grading remain pending.
The implementation work stops here until the next experiment
addresses source verification and a simple-question fast path.
