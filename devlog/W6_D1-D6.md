# W6 D1-D6: Tools, Policy & Security (Milestone 1: v0.1)

**Date:** 2026-11-10

## Built

- **D1 Tool Registry:** Added typed registry in `src/aegisflow/security_tools.py` with 4 read-only tools (`search_logs`, `fetch_runbook`, `get_service_deps`, simulated `query_metrics`) and 1 approval-gated write simulation (`simulate_write`). All tools specify Pydantic schemas (`extra="forbid"`), explicit risk levels, bounded timeouts, and human approval flags. Handled invalid arguments with 1 revalidation retry in `POST /v1/tools/propose`.
- **D2 Central Executor & Audit:** Unified execution flow `validate → policy → timeout → execute → audit` in `ToolExecutor.execute`. Implemented declarative `policy.yaml` with per-tool enablement, execution budgets, and approval overrides. Persisted hashed audit rows in SQLite `tool_audit` table with SHA-256 canonicalized argument hashes; raw arguments are never stored.
- **D3 Untrusted Content & Injection Defense:** Wrapped retrieved passages in `<UNTRUSTED_EVIDENCE>` delimiters, sanitized nested closing tags, and flagged/logged instruction-like patterns without breaking legitimate runbooks. Preserved hard policy enforcement outside prompt context.
- **D4 Automated Red Team:** Implemented dual-mode red team runner in `src/aegisflow/red_team.py` and `evals/run_red_team.py`. Tested 20 injection documents, 10 malicious argument variations, and 5 resource prompts across 5 repetitions (175 total trials) with 0 policy bypasses. Added model-loop mode (`--model-loop`) reporting text compliance separately from executor bypasses.
- **D5 Threat Model, Redaction & Auth:** Authored `docs/threat_model.md` mapping OWASP Top 10 for Agentic Applications 2026 (ASI01–ASI10). Implemented secret/PII pattern redaction in `redact_sensitive()` and `JsonRunFormatter`. Added constant-time API-key auth middleware (`X-API-Key`).
- **D6 M1 Release & Verification:** Rewrote `README.md` v0 with architecture, quickstart, and cited answer inspection. Created interactive 2-minute demo runner `scripts/demo.py`, narration script `docs/demo.md`, and captured transcript `results/demo_transcript.txt`. Tagged `v0.1`.
